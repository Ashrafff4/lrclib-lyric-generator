# Lrclib Lyric Generator

A modern, fast, and sleek web application designed to generate synchronized `.lrc` (lyric) files in real time. Built to interface with LRCLIB and custom audio workflows, featuring integrated online lyric fetching, instant timestamping, dark/light mode toggling, and intuitive keyboard controls.

![Lrclib Lyric Generator Banner](https://github.com/user-attachments/assets/df06a27d-d6f6-4fa1-888d-ef65f8776834)

---

## Features

* **Online Lyric Search:** Integrated search functionality to find, fetch, and auto-paste song lyrics directly into the editor.
* **One-Click Live Sync:** Start manual live synchronization seamlessly with a single action button.
* **Live Timestamp Sync:** Tag lyrics line-by-line in real time with a single keypress.
* **Instant Undo & Rewind:** Undo the last tag and automatically rewind audio by 2.5 seconds to correct mistakes instantly.
* **Dynamic Dual Themes:** Seamlessly switch between a glowing dark glassmorphic UI and a clean light UI.
* **Custom Audio Player:** Load local audio files (`.mp3`, `.wav`, etc.) directly into the browser.
* **One-Click LRC Export:** Export and download completed synchronized `.lrc` files instantly.
* **Fully Responsive:** Optimized layout across desktop, tablet, and mobile devices.

---

## Workflow

1. **Load Audio:** Select and upload your audio file (`.mp3`, `.wav`) using the file picker.
2. **Fetch Lyrics:** Search for lyrics online directly within the app to auto-paste them into the editor, or paste raw lyrics manually.
3. **Start Sync:** Click the **Start Live Sync Mode** button to initialize the synchronization session.
4. **Tag Lines:** Use keyboard shortcuts while playing the track to tag timestamps line-by-line.
5. **Export:** Click **Download LRC** to save your synchronized lyric file.

---

## Keyboard Shortcuts

| Key | Action |
| :--- | :--- |
| **DOWN ARROW** | Tag timestamp for the current lyric line |
| **UP ARROW** | Undo last tagged line and rewind audio by 2.5s |
